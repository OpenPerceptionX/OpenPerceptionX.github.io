# EgoHumanoid-V2 assets

This folder keeps site source and JSON metadata. Media is served from:

`https://assets.archonrobotics.tech/odl/project/EgoHumanoid-V2/`

CDN object names flatten project-relative paths with `__`, e.g.
`assets/videos/human-laptop.mp4` becomes `assets__videos__human-laptop.mp4`.
Upload new media before updating references. Do not add video/image/font/PDF/ZIP
files back to this website repository. Keep font licenses with the CDN font files.

Migration and verification: [CDN handoff](../../docs/egohumanoid-v2-cdn-migration.md).
